# 화면 명세 (Screen Specifications)

safety-nation 단일 페이지 6 섹션 상세 명세

---

## 개요

safety-nation은 **단일 HTML 페이지**로 구성된 시스템입니다.  
사용자는 페이지를 아래로 스크롤하면서 6개 섹션을 순차적으로 이용합니다.

### 레이아웃 요약
```
§0 헤더 (고정)
§1 학교 분포 맵 (F1)
§2 특보 모니터링 (F2)
§3 보고서 초안 (F3)
§4 보고서 이력·검색 (F4, 신규)
§5 통계 대시보드 (F5, 신규)
```

---

## §0 헤더

- 스티키 위치 (스크롤 시 고정)
- 배경: #0b1020
- 텍스트: "safety-nation" + 환경 배지 (DEMO / 운영)

---

## §1 학교 분포 맵 (F1)

### 컴포넌트
- Leaflet 맵 (높이 400px, 12K 마커 + markercluster)
- 시도 드롭다운 (17개 + 전국)
- 학교급 체크박스 (초/중/고)
- 마커 팝업 (클릭 시)

### 성능
- 첫 로드: ≤ 2초
- API 응답: ≤ 100ms
- 필터 적용: ≤ 500ms

### 사용자 동선
1. 시도 선택 → 마커 필터 + 카메라 flyTo (D-lite, 1초)
2. 학교급 체크/해제 → 마커 즉시 업데이트
3. 마커 클릭 → 팝업 (학교명, 시도, 급, ID)

---

## §2 특보 모니터링 (F2)

### 컴포넌트
- 활성 특보 카드 목록
- 각 카드: 발령 시각, 유형, 영향 지역, 영향학교 수, 위험도
- 버튼: [매칭], [상세보기]

### 동작
- "매칭" 클릭 → `/api/alerts/match` 호출
- 영향학교 식별 (≤ 5초)
- §1 마커 붉은 테두리로 강조
- §3 자동 업데이트

### 상태
- 활성 특보 없음: "현재 활성 특보가 없습니다"
- 로딩: "매칭 중..."

---

## §3 보고서 초안 (F3)

### 컴포넌트
1. Disclaimer 배너 (빨간색, 눈에 띄게)
2. 액션 바: [생성], [저장], [인쇄]
3. 보고서 텍스트 (마크다운 렌더링, 읽기 전용)
4. 영향학교 테이블 (학교명, 시도, 급, 위험도)
5. 메타정보 (출처: SDK/CLI/Template, 처리시간)

### 성능
- 생성 시간: P95 ≤ 30초
- AI 실패 시 template fallback (자동, 다운타임 0)
- 로딩 애니메이션: "AI 보고서 작성 중..."

### 저장
- "저장" 클릭 → SQLite에 저장
- F4 이력 테이블에 즉시 표시

---

## §4 보고서 이력·검색 (신규, F4)

### 컴포넌트
1. 검색 필터
   - 특보 유형 드롭다운 (16종 + "모두")
   - 지역 드롭다운 (17개 시도 + "모두")
   - 날짜 범위 (from ~ to)
   - [검색] 버튼

2. 보고서 테이블
   - 컬럼: 생성시각 | 특보유형 | 지역 | 학교수 | 출처
   - 행 클릭 → §3에 보고서 로드
   - 줄무늬 배경 (읽기 편함)

3. 페이지네이션 (선택)
   - 기본 10개/페이지

### 동작
- 검색 조건 입력 → [검색] 클릭
- 필터 적용 ≤ 1초
- 유사 사례 자동 추천 (상단에 "유사 사례" 섹션)

---

## §5 통계 대시보드 (신규, F5)

### 기간 선택
- 드롭다운: "최근 7일" / "최근 30일" / "전체"
- 기본값: "최근 30일"

### 4종 Chart.js 차트 (2x2 레이아웃)

#### Chart 1: 기간별 처리량
- 타입: Line 또는 Bar
- X축: 날짜, Y축: 건수
- 색상: #3b82f6 (파란색)

#### Chart 2: 시도별 영향학교
- 타입: Horizontal Bar
- Y축: 17개 시도, X축: 영향학교 수
- 색상: #8b5cf6 (보라색)

#### Chart 3: AI 출처 분포
- 타입: Doughnut
- 범주: CLI / SDK / Template
- 범례: 각 모드명 + 건수 + 백분율

#### Chart 4: 처리시간 분포
- 타입: Bar
- 범주: P50 / P95 / Max
- 색상: #06b6d4 (시안색)

### 성능
- 로드: ≤ 2초
- 기간 변경 시 업데이트: ≤ 2초

---

## 기술 명세

### HTML 구조
- 단일 `index.html` 파일
- 6개 `<section>` (§0~§5)

### CSS
- 들여쓰기: 2 스페이스
- 다크 모드: #0b1020 배경
- 반응형: 모바일 (100% 너비)
- prefers-reduced-motion 지원

### JavaScript
- 바닐라 (프레임워크 없음)
- async/await 권장
- fetch + AbortController (타임아웃)

### 라이브러리 (CDN)
- Leaflet 1.9.4
- Leaflet.markercluster 1.5.3
- Chart.js 4.x

## 통합 시나리오: 특보 발령 → 보고서 생성 → 저장 → 통계 확인

```
1. 페이지 진입
   └─> §0 헤더 표시 (DEMO 모드)
   └─> §1 지도 로드 (12K 마커, 2초)

2. 특보 모니터링
   └─> §2 활성 특보 카드 로드
   └─> P1 "매칭" 클릭

3. 영향학교 식별
   └─> /api/alerts/match 호출 (5초)
   └─> §1 마커 강조
   └─> 영향학교 목록 반환

4. 보고서 생성
   └─> /api/reports/draft 자동 호출
   └─> §3에 초안 + 테이블 표시 (10초)

5. 보고서 저장
   └─> P1 "저장" 클릭
   └─> SQLite 저장

6. 이력 조회
   └─> §4 스크롤
   └─> /api/reports/list 로드
   └─> 새 보고서가 테이블 상단에 표시

7. 통계 확인 (P3)
   └─> §5 스크롤
   └─> /api/stats/summary 로드
   └─> 4종 차트 렌더링 (2초)
```
