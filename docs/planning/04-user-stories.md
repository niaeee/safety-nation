# 사용자 스토리 (User Stories)

safety-nation의 사용자 스토리 정의 및 인수기준

---

## 사용자 스토리 형식

```
AS A [페르소나]
I WANT [기능]
SO THAT [가치]

ACCEPTANCE CRITERIA:
- AC-1. [조건]
- AC-2. [조건]
- AC-3. [조건]
```

---

## F1. 학교 정보 조회·시각화

### US-1.1: 시도별 학교 필터링

**AS A** P1 시도 담당 공무원  
**I WANT** 특정 시도의 학교만 지도에 표시  
**SO THAT** 광역 수준의 영향학교를 빠르게 파악

**ACCEPTANCE CRITERIA:**
- AC-1.1.1: 17개 시도 선택 박스에서 1개 이상 선택 가능
- AC-1.1.2: 선택 후 0.5초 내 마커 필터 적용
- AC-1.1.3: 선택 해제 시 모든 시도 학교 재표시

---

### US-1.2: 학교급별 필터링

**AS A** P2 단위학교 안전 담당교사  
**I WANT** 초등학교만 또는 중고등학교만 보기  
**SO THAT** 학교급별 특보 영향도를 따로 분석

**ACCEPTANCE CRITERIA:**
- AC-1.2.1: 초/중/고 체크박스 독립 선택 가능
- AC-1.2.2: 복수 선택 가능 (예: 초등학교 + 중학교)
- AC-1.2.3: 선택 조합 변경 시 마커 즉시 업데이트

---

### US-1.3: 학교 상세정보 조회

**AS A** P1 시도 담당 공무원  
**I WANT** 지도의 학교 마커를 클릭하면 학교명/시도/학교급/ID를 팝업으로 본다  
**SO THAT** 영향학교의 정확한 정보를 확인

**ACCEPTANCE CRITERIA:**
- AC-1.3.1: 마커 클릭 → 팝업 자동 표시 (200ms 이내)
- AC-1.3.2: 팝업에 학교명, 시도, 학교급, 학교ID 포함
- AC-1.3.3: 팝업 외 영역 클릭 시 팝업 자동 닫힘

---

### US-1.4: 빠른 첫 로딩

**AS A** P3 정책 수립자  
**I WANT** 앱 접속 후 지도가 2초 내에 로드  
**SO THAT** 빠르게 데이터 조회 시작

**ACCEPTANCE CRITERIA:**
- AC-1.4.1: 12,011개 마커 렌더링 완료 ≤ 2초 (Railway 기준)
- AC-1.4.2: 로딩 중 "지도 로드 중..." 메시지 표시
- AC-1.4.3: 마커 클러스터링으로 초기 렌더링 최적화

---

### US-1.5: 매끄러운 지역 전환

**AS A** P1 시도 담당 공무원  
**I WANT** 시도를 바꿀 때 지도 카메라가 부드럽게 전환  
**SO THAT** 지도 조작이 자연스럽고 시각적 편의성 향상

**ACCEPTANCE CRITERIA:**
- AC-1.5.1: 시도 변경 시 flyTo 애니메이션 1초 진행
- AC-1.5.2: prefers-reduced-motion 설정된 사용자는 즉시 전환 (애니메이션 제거)
- AC-1.5.3: 애니메이션 중 상호작용 가능

---

## F2. 특보 모니터링·매칭

### US-2.1: 활성 특보 목록 조회

**AS A** P1 시도 담당 공무원  
**I WANT** 현재 발령 중인 특보 목록을 카드로 본다  
**SO THAT** 어떤 특보에 대응해야 하는지 즉시 파악

**ACCEPTANCE CRITERIA:**
- AC-2.1.1: 활성 특보 카드 목록 표시 (최대 10개)
- AC-2.1.2: 각 카드에 발령 시각, 특보 유형, 영향 지역, 영향 학교 수 표시
- AC-2.1.3: 데모 모드에서는 fixture 특보 표시
- AC-2.1.4: 비활성 특보는 회색으로 표시, 클릭 불가

---

### US-2.2: 특보별 영향학교 자동 매칭

**AS A** P2 단위학교 안전 담당교사  
**I WANT** 특보 카드를 클릭하면 내 학교가 영향권에 있는지 즉시 알 수 있다  
**SO THAT** 신속하게 학교장에게 보고

**ACCEPTANCE CRITERIA:**
- AC-2.2.1: 특보 카드 클릭 → 매칭 API 호출 (≤ 5초)
- AC-2.2.2: 매칭 결과: 영향학교 목록 + 테이블 표시
- AC-2.2.3: 영향학교 수 + 학교급 분포 표시
- AC-2.2.4: 지도 마커 중 영향학교를 붉은 테두리로 강조

---

### US-2.3: region 기반 정확한 매칭

**AS A** 시스템  
**I WANT** 특보의 영향 시군구와 학교의 소재지를 정확히 매칭  
**SO THAT** 100% 정확도로 영향학교 식별

**ACCEPTANCE CRITERIA:**
- AC-2.3.1: 17개 시도 region명 정확히 일치 (예: "서울특별시", "부산광역시" 등)
- AC-2.3.2: 매칭 결과는 결정론적 (같은 입력 → 항상 같은 출력)
- AC-2.3.3: 매칭 결과 단위 테스트 통과 (17개 시도 모두)

---

### US-2.4: 위험도 점수 계산

**AS A** P1 시도 담당 공무원  
**I WANT** 영향학교 목록에 학교급별 위험도 점수가 표시  
**SO THAT** 고위험군부터 우선순위를 정할 수 있다

**ACCEPTANCE CRITERIA:**
- AC-2.4.1: 위험도 점수 = 학교급별 가중치 (초등 1.0, 중 0.8, 고 0.6)
- AC-2.4.2: 영향학교 테이블에 "위험도" 열 표시
- AC-2.4.3: 위험도 점수 내림차순으로 정렬

---

## F3. AI 보고서 초안 자동 생성

### US-3.1: 보고서 초안 생성 요청

**AS A** P1 시도 담당 공무원  
**I WANT** "보고서 생성" 버튼을 클릭하면 AI가 초안을 만들어 준다  
**SO THAT** 처음부터 작성하지 않고 검토만 하면 된다

**ACCEPTANCE CRITERIA:**
- AC-3.1.1: 버튼 클릭 → 보고서 생성 시작 (로딩 애니메이션)
- AC-3.1.2: 생성 완료 후 초안 텍스트 §3에 표시
- AC-3.1.3: 처리시간 표시 (예: "9초 소요")

---

### US-3.2: 보고서 처리시간 보증

**AS A** P1 시도 담당 공무원  
**I WANT** 보고서 생성이 30초 내에 완료  
**SO THAT** 특보 발령 후 30분 내 보고 가능

**ACCEPTANCE CRITERIA:**
- AC-3.2.1: P95 처리시간 ≤ 30초 (10회 측정 상위 95%)
- AC-3.2.2: 타임아웃 발생 시 자동으로 template fallback 적용
- AC-3.2.3: 다운타임 0% (항상 최소 초안 제공)

---

### US-3.3: AI 보조판단 명시

**AS A** P1 시도 담당 공무원  
**I WANT** 보고서 상단과 하단에 "AI 보조판단, 담당자 검토 필수" disclaimer 표시  
**SO THAT** AI 한계를 명확히 인식하고 책임 있게 사용

**ACCEPTANCE CRITERIA:**
- AC-3.3.1: 보고서 상단에 disclaimer 배너 표시 (빨간색, 눈에 띄게)
- AC-3.3.2: 보고서 하단에도 작은 글씨 disclaimer 포함
- AC-3.3.3: 모든 출력 채널(화면/인쇄/다운로드)에서 표시

---

### US-3.4: 보고서 생성 출처 명시

**AS A** 시스템  
**I WANT** 보고서 메타데이터에 생성 출처(cli/sdk/template) 기록  
**SO THAT** AI 활용도를 측정하고 추후 개선에 활용

**ACCEPTANCE CRITERIA:**
- AC-3.4.1: draft.source 필드에 'cli', 'sdk', 'template' 중 하나 기록
- AC-3.4.2: 화면에 출처 표시 (예: "[SDK 모드 생성]")
- AC-3.4.3: 로그에도 기록 (benchmark.jsonl)

---

### US-3.5: 영향학교 테이블 포함

**AS A** P1 시도 담당 공무원  
**I WANT** 보고서에 영향학교 목록을 표 형식으로 포함  
**SO THAT** 보고서만으로도 영향 정도를 파악

**ACCEPTANCE CRITERIA:**
- AC-3.5.1: 테이블에 학교명, 시도, 학교급, 위험도 열 포함
- AC-3.5.2: 위험도 내림차순 정렬
- AC-3.5.3: 영향학교 수가 적으면(≤ 20개) 모두 표시, 초과하면 상위 20개 + "외 N개"

---

## F4. 보고서 저장·검색·이전 사례 참조

### US-4.1: 보고서 저장

**AS A** P1 시도 담당 공무원  
**I WANT** "저장" 버튼을 클릭하면 현재 보고서를 DB에 저장  
**SO THAT** 나중에 검색하여 참조 가능

**ACCEPTANCE CRITERIA:**
- AC-4.1.1: "저장" 버튼 클릭 → 로딩 (1초 내)
- AC-4.1.2: 저장 완료 후 메시지 "보고서가 저장되었습니다"
- AC-4.1.3: SQLite에 ts, alert_type, alert_region, schools_affected, draft_text, source 저장

---

### US-4.2: 보고서 검색

**AS A** P1 시도 담당 공무원  
**I WANT** "이전 보고서" 섹션에서 특보 유형·지역·날짜로 검색  
**SO THAT** 유사 사례를 찾아 참조

**ACCEPTANCE CRITERIA:**
- AC-4.2.1: 검색 박스에 특보 유형 입력 (예: "호우주의보")
- AC-4.2.2: 지역 선택 (예: "서울특별시")
- AC-4.2.3: 날짜 범위 선택 (예: "최근 1개월")
- AC-4.2.4: "검색" 버튼 클릭 → 테이블에 필터 결과 표시 (0.5초 내)

---

### US-4.3: 이전 사례 자동 추천

**AS A** P1 시도 담당 공무원  
**I WANT** 특보 유형을 선택하면 자동으로 최근 3건의 유사 사례가 추천  
**SO THAT** 의사결정 참고 가능

**ACCEPTANCE CRITERIA:**
- AC-4.3.1: 특보 유형 선택 후 자동 쿼리 (≤ 1초)
- AC-4.3.2: 상단에 "유사 사례" 섹션 표시
- AC-4.3.3: 최근순으로 상위 3건 표시
- AC-4.3.4: 각 사례에 생성 시각, 영향학교 수 표시

---

### US-4.4: 저장된 보고서 조회

**AS A** P1 시도 담당 공무원  
**I WANT** 테이블의 행을 클릭하면 해당 보고서가 §3에 다시 표시  
**SO THAT** 과거 보고서 내용 검토 가능

**ACCEPTANCE CRITERIA:**
- AC-4.4.1: 테이블 행 클릭 → 보고서 로드 (≤ 1초)
- AC-4.4.2: §3에 보고서 전문 표시
- AC-4.4.3: 메타데이터(생성 시각, 출처 등) 표시
- AC-4.4.4: "저장" 버튼 대신 "이 보고서로부터 새 보고서 생성" 등 옵션

---

## F5. 통계 대시보드

### US-5.1: 기간 선택

**AS A** P3 교육행정 정책 수립자  
**I WANT** "최근 7일", "최근 30일", "전체" 중 하나를 선택  
**SO THAT** 다양한 시간 단위로 분석 가능

**ACCEPTANCE CRITERIA:**
- AC-5.1.1: 드롭다운에 3개 옵션 제공
- AC-5.1.2: 기본값은 "최근 30일"
- AC-5.1.3: 선택 후 자동으로 차트 업데이트 (≤ 2초)

---

### US-5.2: 기간별 처리량 차트

**AS A** P3 교육행정 정책 수립자  
**I WANT** 일별/주별/월별 보고서 생성 건수를 꺾은선 또는 막대 차트로 본다  
**SO THAT** 시간대별 트렌드 파악

**ACCEPTANCE CRITERIA:**
- AC-5.2.1: X축: 날짜, Y축: 건수
- AC-5.2.2: 호버 시 정확한 수치 표시
- AC-5.2.3: 기간 내 데이터 모두 표시
- AC-5.2.4: 색상은 다크 모드 (#0b1020 배경)에 맞춤 (밝은 파란색 등)

---

### US-5.3: 시도별 영향학교 히트맵

**AS A** P3 교육행정 정책 수립자  
**I WANT** 17개 시도별로 총 영향학교 수를 히트맵 또는 막대 차트로 본다  
**SO THAT** 지역별 특보 영향 분포 파악

**ACCEPTANCE CRITERIA:**
- AC-5.3.1: 17개 시도 모두 포함
- AC-5.3.2: 영향학교 수를 색상 진하기로 표현 (또는 막대 길이)
- AC-5.3.3: 호버 시 시도명 + 정확한 수치 표시
- AC-5.3.4: 기간 필터 적용

---

### US-5.4: AI 출처 분포

**AS A** P3 교육행정 정책 수립자  
**I WANT** cli/sdk/template 모드별 생성 건수를 도넛 차트로 본다  
**SO THAT** AI 활용도 및 fallback 사용도 측정

**ACCEPTANCE CRITERIA:**
- AC-5.4.1: 도넛 차트에 3개 구간 (cli, sdk, template)
- AC-5.4.2: 범례에 각 모드명 + 건수 표시
- AC-5.4.3: 호버 시 백분율 표시
- AC-5.4.4: 기간 필터 적용

---

### US-5.5: 처리시간 분포

**AS A** P3 교육행정 정책 수립자  
**I WANT** 보고서 생성 처리시간의 P50, P95, 최대값을 박스플롯 또는 막대 차트로 본다  
**SO THAT** 성능 지표 추적

**ACCEPTANCE CRITERIA:**
- AC-5.5.1: 3개 막대: P50, P95, Max
- AC-5.5.2: Y축은 초(sec) 단위
- AC-5.5.3: 호버 시 정확한 수치 표시
- AC-5.5.4: 기간 필터 적용

---

### US-5.6: 차트 인터랙션

**AS A** P3 교육행정 정책 수립자  
**I WANT** 차트의 범례를 클릭하여 데이터 시리즈 토글  
**SO THAT** 관심 데이터만 집중해서 본다

**ACCEPTANCE CRITERIA:**
- AC-5.6.1: 범례 클릭 → 해당 시리즈 표시/숨김
- AC-5.6.2: 복수 시리즈 토글 가능
- AC-5.6.3: 토글 상태 유지 (페이지 새로고침 전까지)
