## 1. 비전 재정의 (사용자 직접 표현)

> **기상청 API로 특보가 내려졌을 때 시도별로 위험도가 높은 학교를 추출해서 시각적으로 위험도를 알려주고, AI가 사전 예측 보고서를 작성한다.**
> 자동 안내문자는 **v2 보류** (사용자 직접 명시).
> "실제로 사용 가능한 예측 시스템"을 지향. 위험도 산정은 풍부하게 + plug-in 구조.
