### 검증 가능성 강화 약속 (v1.1 신설)

본 시스템은 출력의 **정확성보다 검증 가능성**을 우선시한다.
- AI 보고서에 **근거 인용 표시** (어느 매뉴얼 조항·매칭 학교에서 끌어왔는지)
- 담당자 **편집 가능 + diff 로깅**
- 매 보고서에 **정확도 피드백** 1-클릭 입력 → 통계 대시보드 노출

## 1. 비전 및 원라이너 *(v1.2 개정)*

> **AI 사전 예측 시스템.** 기상특보 발령 시 영향권 학교를 능동 식별하고, AI가 사전 대비 보고서 초안을 자동 생성한다.
> 안전 담당자는 보고서를 새로 작성하지 않고 **검토·결재만**, 학부모는 자녀 학교 위험 여부를 한눈에 확인.

**핵심 강조어** *(Eros Cycle 2 결과 반영)*:
- "사고 후 보고서"가 아닌 **"사고 전 능동 푸시"**
- 시연·기획서에서 "사전 예측" 비중을 "사후 보고"보다 높게

### 1.1 시연 핵심 경로 *(v1.3 + 코덱스 검토 반영)*

> **시청 안전문자 → 좌표 → 반경 학교 → 위험도 → AI 보고서**

이 경로 하나를 끝까지 완성하는 것이 D-7 최우선 목표.
기능 추가가 아니라 **범위 절단**으로 안전 확보. 기능 우선순위는 §5 또는 `08-upgrade-roadmap.md` 참조.

## 2. 배경 및 문제 정의

### 2.1 학교 안전 담당자가 직면하는 4가지 부담

| # | 부담 | 현장 현황 | 영향 |
|---|---|---|---|
| B1 | **시간** | 영향 학교 수십~수백 개를 행정구역과 매칭하여 일일이 식별 | 특보 발령 후 2~4시간 소요 |
| B2 | **작성** | 특보 유형별 매뉴얼·표준 문구를 보고서에 매번 옮겨 적음 | 초안 작성에 1~2시간 |
| B3 | **정보** | 학교 위치·특보 영향권을 분리된 자료로 파악 | 의사결정 근거 불충분 |
| B4 | **결정** | 휴교/등교 조정 등 의사결정에 객관적 근거 부족 | 정책 결정 지연 |

### 2.2 기존 시스템의 한계

- 행정 절차 중심, 공공데이터 결합 미흡
- AI 보조 판단 기능 부재
- 광역·단위학교 간 정보 비대칭

## 3. 사용자 페르소나 (Personas)

### P1: 시도/지원청 안전 담당 공무원 (우선순위 1순위)

**역할**: 광역 수준의 재난 모니터링 및 보고  
**주요 사용 시점**: 특보 발령 시 (호우주의보, 강풍주의보 등)  
**일일 업무량**: 특보 발령 시 1~3건, 비발령 시 0건  

**가치**: 
- 30분 내에 영향 학교를 식별하고 보고서 초안을 받음
- 광역 데이터를 한눈에 조회
- 이전 유사 특보 사례 참조 가능

**사용 시나리오**: 호우주의보 발령 → 시스템 진입 → 영향 시군구 자동 식별 → 보고서 초안 수신 → 담당관에게 보고

---

### P2: 단위학교 안전 담당교사 (우선순위 2순위)

**역할**: 본인 학교의 재난 영향 확인 및 학교장 보고  
**주요 사용 시점**: 특보 발령 알림 수신 후  
**일일 업무량**: 특보 발령 시 1건  

**가치**:
- 자신의 학교가 영향권에 있는지 명확히 확인
- 다른 학교의 대응 사례 참조
- 학교장과의 의사결정 근거 제시

**사용 시나리오**: 특보 발령 → 본인 학교 검색 → 영향도 확인 → 학교장 긴급 보고

---

### P3: 교육행정 정책 수립자 (우선순위 3순위)

**역할**: 기후변화 대응 교육 정책 수립을 위한 데이터 수집  
**주요 사용 시점**: 분기/반기 단위 통계 수집  
**일일 업무량**: 주 1회, 30분  

**가치**:
- 시도별 특보 처리 현황 통계
- 연도별 트렌드 분석
- 정책 입안 근거 제시

**사용 시나리오**: 분기 보고 → 시스템 통계 대시보드 진입 → 시도별 히트맵·처리량 조회 → 보고서 작성

---

### P4: 학부모 *(v1.2 신설)*

**역할**: 자녀가 다니는 학교의 재난 영향 실시간 확인
**주요 사용 시점**: 특보 발령 알림 수신 후 (현재는 일반 재난문자 + 사이트 접속 + v2에서 push)
**일일 업무량**: 비발령 시 0건, 발령 시 1~2회 확인

**가치**:
- "오늘 우리 아이 학교 가도 되나?" 즉시 답
- 자녀 학교 위험도 색상 즉시 인지
- 안심 또는 능동 대응 (일찍 등교, 우산 챙기기 등)

**사용 시나리오**: 특보 인지 → 메인 페이지 학부모 검색 박스 → 학교명 입력 → 위험 아이콘 즉시 표시

> **검증**: 학부모 행동 패턴은 인터뷰 없는 **(추정)**. 출품 후 사용자 피드백으로 검증.

---

### P5: 학교 재난 담당자 *(v1.2 신설)*

**역할**: 본인 학교의 사전 대비 (하수도 정비, 문 닫기, 시설 점검)
**주요 사용 시점**: 특보 발령 인지 직후
**일일 업무량**: 비발령 시 0건, 발령 시 즉시 점검 1~3시간

**가치**:
- 자기 학교의 현재 위험도 즉시 인지
- AI 사전 권고 (예: "노후 하수관 점검 권장")
- 매뉴얼 조항 인용으로 행동 근거 확보

**사용 시나리오**: 특보 인지 → 본인 학교 검색 또는 지도에서 클릭 → 위험도·근거 확인 → 사전 점검 항목 실행

- 실시간 협업 / 다중 사용자 동시 편집
- 결재 인증서 통합

## 5. 핵심 기능 (15대 기능 — v1.3 확장)

> v1.0 F1~F5 + v1.2 신규 F6/F7 + F2 위험도 풀 강화 + **v1.3 근본 사이트 이식 F8~F15**.
> v1.3 통합 의의: 본 시스템 = "전국 위치 + 울산 풍부 메타 + AI 보조 + 근본 사이트 풀 기능"

### F1. 학교 정보 조회·시각화

**목적**: 사용자가 지도에서 전국 학교 분포를 시각적으로 조회하고 필터링

**입력**: 시도명, 학교급(초/중/고), 지도 영역

**출력**: 지도 마커 (위치 기반), 팝업 (학교명/시도/급/ID)

**인수기준**:
- 17개 시도 + 3개 학교급 다중선택 가능
- 마커 클릭 → 학교 상세정보 팝업
- 12K 마커 첫 로드 ≤ 2초 (Railway 기준)
- 시도 변경 시 매끄러운 카메라 전환 (D-lite 패턴)

**의존성**: 없음 (초기 로드)

**우선순위**: P0 (필수)

---

### F2. 특보 모니터링·매칭

**목적**: 기상특보를 실시간 모니터링하고, 영향권 학교를 자동 식별

**입력**: 특보 정보 (지역, 유형, 강도), 학교 마스터 데이터

**출력**: 활성 특보 목록, 매칭된 학교 목록, 위험도 점수

**인수기준**:
- 특보 카드에 영향 학교 수 표시
- 특보 클릭 → 영향학교 지도 강조 + 테이블 표시
- 매칭 결과 100% 재현 가능 (결정론)
- 17개 시도 region명 정확히 일치

**의존성**: F1 (지도 준비)

**우선순위**: P0 (필수)

---

### F3. AI 보고서 초안 자동 생성

**목적**: 특보·영향학교·매뉴얼을 입력으로 AI가 보고서 초안을 자동 작성

**입력**: 특보 메타데이터, 영향학교 목록, 표준 매뉴얼 문구

**출력**: 보고서 초안 (마크다운/HTML), 소스 표기 (cli/sdk/template)

**인수기준**:
- 보고서 생성 P95 처리시간 ≤ 30초

## 12. 운영 원칙

1. **AI는 보조판단, 결재는 사람**
   - 모든 보고서 출력에 "AI 보조판단, 담당자 검토 필수" disclaimer 고정 표시
   - 책임 영역 명확: 시스템은 초안 제공만, 최종 승인은 담당자

2. **DEMO_MODE 기본 ON**
   - 운영 데이터 로딩 차단이 기본값
   - 시연 환경과 운영 환경 자동 분리

3. **AI 실패 안전성**
   - claude -p timeout 60초 설정
   - timeout 시 TemplateDrafter fallback으로 최소 초안 자동 생성
   - 다운타임 0% 목표

4. **룰 기반 영향도는 AI 아님**
   - region 매칭·위험도 점수는 결정론적 알고리즘
   - AI 활용도는 보고서 초안 생성에서만 입증

5. **빌드 멱등성**
   - 같은 입력 데이터 → 같은 출력 (결정론)
   - 운영 중 재배포로 안전하게 데이터 갱신 가능
   - git diff로 데이터 변경사항 검증 가능

## 13. 차별화 포인트

### 1순위: 공공데이터 3종 결합

- **학교알리미** (교육부): 학교 마스터 데이터 (12,011건)

이 3종을 결합한 학교-특보 자동 매칭 시스템은 교육 분야 최초 (예상)

### 2순위: AI는 보조판단, 결재는 사람

기존 시스템은 AI 판단을 그대로 따르지만, safety-nation은:
- 영향학교 식별 = 결정론 (100% 객관성)
- 보고서 초안 생성 = AI 보조 (담당자 필수 검토)
- 최종 승인 = 사람 (책임 영역 명확)

→ AI 활용도는 높으면서도 책임을 명확히 함
